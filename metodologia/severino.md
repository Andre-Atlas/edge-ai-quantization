# Fundamentação: Antônio Joaquim Severino — *Metodologia do Trabalho Científico*

Este é o eixo **estrutural** do projeto: orienta como organizar leitura, registro e redação do texto científico.

## 1. Leitura e estudo de textos (aplicado ao mapeamento bibliográfico)

Severino propõe leitura em etapas, que adotamos para cada artigo da lista:

1. **Análise textual** — visão global: autor, contexto, vocabulário, esquema do texto.
2. **Análise temática** — qual é o tema, o problema, a tese do autor, como argumenta.
3. **Análise interpretativa** — situar o autor, associar ideias, avaliar criticamente.
4. **Problematização** — levantar questões que o texto suscita para o *nosso* problema.
5. **Síntese pessoal** — reelaborar o que foi aprendido.

→ Cada artigo vira uma ficha em `literatura/fichas/` (modelo em [`ficha-modelo.md`](ficha-modelo.md)).

## 2. Documentação e registro
Tipos de registro: **resumo**, **resenha**, **fichamento** (bibliográfico, de citações, de conteúdo/ideias). Usamos fichamento de conteúdo + citações diretas curtas com página.

## 3. Pesquisa científica e projeto
- Pesquisa **bibliográfica** (nossa fase atual), com possível etapa **experimental** (medição de acurácia/latência/memória de modelos quantizados).
- Elementos do **projeto de pesquisa**: tema, problema, hipótese, objetivos (geral/específicos), justificativa, metodologia, referencial teórico, cronograma, referências.

## 4. Estrutura do trabalho científico / artigo
Artigo científico, na lógica de Severino: **introdução** (tema, problema, objetivos, justificativa) → **desenvolvimento** (referencial, método, resultados/discussão) → **conclusão** (retomada de problema/objetivos, contribuições, limites) → **referências**, seguindo normas da ABNT (NBR 6023, 10520, 6022, 14724).

Ver o mapeamento para este projeto em [`estrutura-do-artigo.md`](estrutura-do-artigo.md).
